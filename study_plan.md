# Personalized Data Science Learning Roadmap (6 Months)

**User Profile:** Marketing Coordinator transitioning to Data Analyst/Business Intelligence Analyst

**Learning Goals:** Develop proficiency in data visualization, SQL, and statistical analysis. Obtain Google Data Analytics Professional Certificate and Tableau Desktop Specialist certification.

**Time Commitment:** 10-15 hours per week

**Learning Style:** Structured online courses with hands-on projects.

## Month 1: Foundations - Python, Statistics & Data Analysis

**Weekly Goals:**

*   **Week 1:** Introduction to Python & Jupyter Notebooks
    *   **Resources:**
        *   Coursera: "Python for Everybody" Specialization (Weeks 1-2)
        *   DataCamp: "Introduction to Python"
    *   **Hands-on Project:** Set up Python environment and write basic scripts (e.g., calculating averages, simple functions).
*   **Week 2:** Python Data Structures & Control Flow
    *   **Resources:**
        *   Coursera: "Python for Everybody" Specialization (Weeks 3-4)
        *   DataCamp: "Intermediate Python"
    *   **Hands-on Project:** Create a simple program to analyze a small dataset (e.g., list of sales numbers).
*   **Week 3:** Statistics Fundamentals
    *   **Resources:**
        *   Khan Academy: "Statistics and Probability" (Introduction to descriptive statistics)
        *   DataCamp: "Introduction to Statistics in Python"
    *   **Hands-on Project:** Calculate mean, median, mode, standard deviation for a sample dataset in Python.
*   **Week 4:** Data Analysis with Pandas
    *   **Resources:**
        *   DataCamp: "Data Manipulation with Pandas"
        *   Real Python: "Pandas Tutorial: Data Analysis with Python"
    *   **Hands-on Project:** Load a CSV file into a Pandas DataFrame, clean the data (handle missing values), and perform basic data exploration (e.g., calculate summary statistics).

## Month 2: SQL & Relational Databases

**Weekly Goals:**

*   **Week 5:** Introduction to SQL
    *   **Resources:**
        *   SQLZoo: Interactive SQL Tutorial
        *   Khan Academy: "SQL: Intro to SQL"
    *   **Hands-on Project:** Set up a local database (e.g., SQLite) and create tables.
*   **Week 6:** SQL Queries: SELECT, FROM, WHERE
    *   **Resources:**
        *   DataCamp: "Introduction to SQL"
        *   Mode Analytics SQL Tutorial
    *   **Hands-on Project:** Write SQL queries to retrieve specific data from the tables created in Week 5.
*   **Week 7:** SQL Queries: JOINs, GROUP BY, ORDER BY
    *   **Resources:**
        *   DataCamp: "Intermediate SQL"
        *   LeetCode: SQL Problems (Easy)
    *   **Hands-on Project:** Write SQL queries to join multiple tables, group data, and order the results.
*   **Week 8:** Advanced SQL Concepts & Subqueries
    *   **Resources:**
        *   DataCamp: "SQL for Business Analysts"
        *   W3Schools: SQL Tutorial
    *   **Hands-on Project:** Write SQL queries using subqueries to solve complex data retrieval problems.

## Month 3: Data Visualization with Tableau

**Weekly Goals:**

*   **Week 9:** Introduction to Tableau
    *   **Resources:**
        *   Tableau: "Getting Started" videos
        *   Coursera: "Data Visualization with Tableau Specialization" (Course 1)
    *   **Hands-on Project:** Download and install Tableau Public. Connect to a sample dataset (e.g., Sample-Superstore) and create basic charts (bar charts, line charts, scatter plots).
*   **Week 10:** Creating Basic Visualizations & Dashboards
    *   **Resources:**
        *   Tableau: "Build Your First Dashboard" tutorial
        *   Tableau Public Gallery: Explore examples of visualizations
    *   **Hands-on Project:** Create a dashboard with multiple visualizations showing different aspects of the Sample-Superstore dataset.
*   **Week 11:** Advanced Chart Types & Calculated Fields
    *   **Resources:**
        *   Tableau: Help documentation on calculated fields
        *   Online tutorials on advanced chart types (e.g., treemaps, heatmaps)
    *   **Hands-on Project:** Create calculated fields to derive new metrics from existing data. Experiment with advanced chart types to visualize the data.
*   **Week 12:** Interactive Dashboards & Storytelling
    *   **Resources:**
        *   Tableau: "Story Points" tutorial
        *   Tableau Public Gallery: Explore interactive dashboards
    *   **Hands-on Project:** Create an interactive dashboard with filters and actions. Build a story using Tableau's story points feature to present your findings.

## Month 4: Google Data Analytics Professional Certificate - Focus

**Weekly Goals:**

*   **Week 13-16:** Complete Google Data Analytics Professional Certificate on Coursera (Courses 1-4).
    *   **Resources:**
        *   Coursera: Google Data Analytics Professional Certificate
        *   Course materials, videos, quizzes, and hands-on labs within the Coursera specialization.
    *   **Hands-on Project:** Complete all the projects and exercises within the Google Data Analytics Professional Certificate courses. Focus on data cleaning, analysis, and visualization techniques.

## Month 5: Tableau Desktop Specialist Certification Prep & Portfolio Project

**Weekly Goals:**

*   **Week 17-18:** Tableau Desktop Specialist Exam Preparation
    *   **Resources:**
        *   Tableau Desktop Specialist Exam Guide
        *   Tableau practice exams and sample questions.
        *   Focus on areas for improvement identified during previous Tableau projects.
    *   **Hands-on Project:** Practice exam questions and review Tableau documentation on exam topics.
*   **Week 19-20:** Portfolio Project - Data Analysis & Visualization
    *   **Project Description:** Choose a publicly available dataset (e.g., from Kaggle or government websites) related to an industry of interest (e.g., technology, e-commerce, healthcare).
    *   **Project Steps:**
        1.  **Data Cleaning:** Clean and prepare the data using Python (Pandas) or SQL.
        2.  **Data Analysis:** Perform exploratory data analysis to identify trends and patterns.
        3.  **Data Visualization:** Create interactive dashboards and visualizations in Tableau to communicate your findings.
        4.  **Report Writing:** Write a report summarizing your analysis and insights.

## Month 6: Refinement, Networking & Job Search

**Weekly Goals:**

*   **Week 21-22:** Project Refinement & Portfolio Building
    *   **Activities:**
        *   Refine the portfolio project based on feedback from peers or mentors (if available).
        *   Document the project and create a presentation or blog post to showcase your work.
        *   Create a professional online portfolio (e.g., using GitHub Pages or a personal website).
*   **Week 23-24:** Networking & Job Search Preparation
    *   **Activities:**
        *   Update your LinkedIn profile to highlight your new skills and projects.
        *   Attend online or in-person data science events and meetups.
        *   Practice answering common data science interview questions.
        *   Refine your resume and cover letter to target specific Data Analyst or Business Intelligence Analyst roles.

**Recommended Resources:**

*   **Online Learning Platforms:** Coursera, DataCamp, Udemy, edX, Khan Academy
*   **Data Science Communities:** Kaggle, Towards Data Science (Medium), Reddit (r/datascience)
*   **Tableau Resources:** Tableau Public, Tableau Help Documentation, Tableau Community Forums
*   **SQL Resources:** SQLZoo, Mode Analytics SQL Tutorial, W3Schools SQL Tutorial

**Notes:**

*   This roadmap is a suggestion and can be adjusted based on your individual progress and preferences.
*   Prioritize hands-on projects to build your portfolio and demonstrate your skills to potential employers.
*   Actively participate in online communities and network with other data scientists to learn from their experiences and stay up-to-date with the latest trends.
*   Consider pursuing additional certifications or further education to enhance your career prospects in the long term.
